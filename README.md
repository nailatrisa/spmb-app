# SPMB Modern Admission Platform V2

Sistem Penerimaan Murid Baru yang Modern, Fungsional, Responsif, dan Interaktif.

## Fitur

- Landing page modern dengan live admission counter
- Informasi jurusan dan kuota
- Pengumuman sekolah
- Form pendaftaran online dengan stepper
- Nomor pendaftaran unik
- Tracking status pendaftaran
- Kartu pendaftaran dengan QR Code
- Admin dashboard dengan statistik aktual
- CRUD calon siswa, jurusan, sekolah asal, pengumuman
- Settings sekolah

## Tech Stack

- React.js + Vite
- React Router DOM
- Tailwind CSS
- shadcn/ui
- Lucide React
- Supabase (Auth, Database, Storage)
- QR Code
